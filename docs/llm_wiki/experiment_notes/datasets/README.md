# Dataset Experiment Notes

Use this folder for dataset-scoped experiment notes promoted beyond raw result
CSV rows.

Create one subfolder per dataset slug before adding dated notes, for example:

```text
datasets/superconductivity/
datasets/allstate_claims_severity/
datasets/sgemm_gpu_kernel_performance/
```

Each dataset note must name the target, feature policy, split seed, metrics, and
artifact path.
